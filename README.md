## Resumo

Desenvolvedor Full-Stack com mais de 5 anos de experiência em sistemas corporativos, com foco em C#/.NET e Angular. Atuei em um ERP com integrações de pagamento (Pix e cartões), em um sistema de gestão de franquias e no sistema de gestão de projetos do SESC Departamento Nacional.

Aplico DDD e Clean Architecture, trabalho com mensageria (RabbitMQ e Azure Service Bus), AWS e Azure DevOps, com experiência em decisões de arquitetura, definição de processo de deploy e mentoria técnica. Inglês C2 (EF SET).

- **Back-end:** C#, .NET, Entity Framework, APIs RESTful, Node.js (Express), Python (Flask), Java (Spring Boot)
- **Front-end:** Angular, TypeScript, JavaScript, HTML, CSS
- **Arquitetura:** DDD, Clean Architecture, CQRS, microsserviços, event-driven, SOLID
- **Mensageria e dados:** RabbitMQ, Azure Service Bus, SQL Server, PostgreSQL, MongoDB
- **Cloud e DevOps:** AWS, Azure DevOps, Docker, CI/CD, Git
